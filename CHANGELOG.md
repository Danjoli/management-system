# Changelog

All notable changes follow Keep a Changelog and Semantic Versioning.

## [1.0.0] - 2026-10-02

### Added

- Framework-free MVC kernel, dependency container and PDO persistence
- Secure session authentication, CSRF, RBAC and audit trail
- Department, employee, project and financial management modules
- Transactional writes and advanced SQL reports with CSV export
- MySQL migrations, seed data, Docker environment and health endpoint
- Automated tests, PHPStan, PSR-12 and multi-version CI
